### Changed

- `dialecte contrib`'s changelog row: the files that ask for a changelog fragment are `README.md` and anything under `doc/` in every package, plus the package's own list in its package.json, `dialecte.changelog.asking` (paths; a folder ends in `/`). The cli lists its command map there; no other package is asked about a cli file. A bad value fails the row in any package, `changes/` kept or not, naming the field: a `dialecte.changelog` that is no object, an `asking` that is no list, or entries that are no path as git names a changed file (relative, `/` separators, no `./`, `../`, `.` or `//` segment, no backslash, no spaces around, no glob), each named.
- `dialecte rules`: a `raw-git-repository` finding sits on the argument that makes the repository (the `clone`/`init` element of a list written in the call, the reference to a same-file const, the shell string), so a new argument line under an unchanged call is an error, not a warning about a line the change did not add; a `dialecte-allow raw-git-repository` opt-out goes on that argument's line or the one before it.
