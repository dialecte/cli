### Changed

- Every temporary folder the cli makes now lives under one scratch root: `DIALECTE_SCRATCH` when set (the test suite and CI set it), else the workspace's `.worktrees/_scratch` (beside the pool and the trash, on their volume), else `dialecte-scratch` in the system's temporary folder outside every workspace (a workspace is the nearest folder up holding `_commit-plan/` or `.worktrees/`: a lone repository with a `.worktrees/` folder at its root counts as one, so its scratch lands in that folder, inside its working tree; ignore it there). Each folder is named with its purpose prefix and holds a `scratch.json` (`pid`, `startedAt`, `command`). The gate scope and scoped-tests folders, the check key's index copy, the tdd report, base-collect and base-red folders, the hand-over's trial and review indexes, its cli probe and hook log, and the command reference's format folder moved there, and so did `handover run --rehearse`'s rehearsal folder and clone; the hook's `TMPDIR` stays a short folder of its own under the system's short root on macOS and Linux (`dlt-hook-<random>`; the rehearsal folder's `.tmp` on Windows) so a tool's socket path stays within the 104-byte limit.
- `dialecte worktree prune` lists the scratch root's folders: one whose `scratch.json` names a process that is gone and that was made over a day ago goes to the trash (`.worktrees/_trash`, or the root's own `dialecte-trash` outside a workspace); a live, younger or unmarked one is kept with why. A rehearsal hook's temporary folder (`dlt-hook-`) left in the short root by a killed rehearsal is judged the same way, from the `scratch.json` it now holds.
- `dialecte health` and `dialecte inbox` read leaked scratch folders from the scratch root, and for one release also the `dialecte-*` folders earlier versions left in the system's temporary folder and the short root of macOS and Linux, so those are still named; a folder whose `scratch.json` names a live process (a long rehearsal) is no leak, and its age is read from the start that file records.
- `tdd` trashes base-run leftovers from the scratch root (and the system's temporary folder for earlier versions' folders), their owner read from `scratch.json`.

### Added

- `dialecte rules`: `bare-tmpdir` (error, allowable): a production file using the os module's `tmpdir` outside the scratch module (a call or a reference, under an import alias or through the module) is refused, naming `makeScratchFolder`; test files and test support keep their own helpers. Out of its scope: a read of the `TMPDIR` variable and a literal temporary path.
