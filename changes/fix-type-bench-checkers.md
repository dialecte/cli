### Fixed

- `dialecte bench`: tsgo (TypeScript 7 and later) measures with one checker (`--checkers 1`). With its default checkers the instantiation count shifted with the file set, so a trivial extra file read +3.4% and a real +1.9% read +6.7%, tripping the 5% gate on noise. TypeScript 6 and older already check with one checker and get no flag.
- `dialecte bench` records the compiler and its exact version in `baseline.json` (`"compiler": { "name": "tsgo", "version": "7.0.2" }`, `"checkers": 1`). `bench --check` reads every baseline before measuring and gives no verdict against a baseline from another compiler or version, or one that records none: `baseline from tsgo 7.0.1, measured with tsgo 7.0.2: re-baseline in its own commit`, exit 3. Every existing baseline records no compiler, so each package re-baselines (`dialecte bench`) in its own commit.
- `dialecte bench --check` without a `baseline.json` names the missing file and says to run `dialecte bench` to write it, exit 2, where it threw a raw file-read error.
